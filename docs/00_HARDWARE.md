# 🛠️ Совместимое оборудование (Hardware Compatibility)

## 🍓 Raspberry Pi

### ✅ Рекомендуемые модели

| Модель | RAM | WiFi | Ethernet | Рекомендация |
|--------|-----|------|----------|--------------|
| **Raspberry Pi 4 Model B (4GB)** | 4 GB | 2.4/5 GHz | Gigabit | ⭐⭐⭐⭐⭐ **Лучший выбор** |
| **Raspberry Pi 4 Model B (8GB)** | 8 GB | 2.4/5 GHz | Gigabit | ⭐⭐⭐⭐⭐ Избыточно, но отлично |
| **Raspberry Pi 4 Model B (2GB)** | 2 GB | 2.4/5 GHz | Gigabit | ⭐⭐⭐⭐ Минимум для комфорта |
| **Raspberry Pi 5 (4GB/8GB)** | 4-8 GB | 2.4/5 GHz | Gigabit | ⭐⭐⭐⭐⭐ Новейший, быстрый |

### ⚠️ Работает с ограничениями

| Модель | RAM | WiFi | Проблемы |
|--------|-----|------|----------|
| **Raspberry Pi 3 Model B+** | 1 GB | 2.4/5 GHz | Мало RAM, нужен swap 2GB |
| **Raspberry Pi 3 Model B** | 1 GB | 2.4 GHz только | Мало RAM, нет 5GHz WiFi |
| **Raspberry Pi 400** | 4 GB | 2.4/5 GHz | Встроенная клавиатура мешает |

### ❌ НЕ поддерживаются

| Модель | Причина |
|--------|---------|
| Raspberry Pi Zero / Zero W | Слишком слабый CPU, мало RAM |
| Raspberry Pi Zero 2 W | 512MB RAM недостаточно |
| Raspberry Pi 1 / 2 | Устаревшие, нет встроенного WiFi |
| Raspberry Pi Pico | Это микроконтроллер, не компьютер |

## 📡 4G/LTE USB модемы

### ✅ Рекомендуемые модемы

| Модем | Режим | Скорость | Цена (~) | Примечание |
|-------|-------|----------|----------|------------|
| **Huawei E3372h-320** | HiLink (Ethernet) | 150 Mbps | $30-40 | ⭐ **Лучший выбор** |
| **Huawei E3372s** | Stick (PPP) | 150 Mbps | $25-35 | Требует настройки |
| **ZTE MF79U** | WiFi + USB | 150 Mbps | $30-40 | Может быть USB Ethernet |
| **ZTE MF833V** | USB Ethernet | 150 Mbps | $25-30 | Plug-and-play |
| **Alcatel IK40V** | USB Ethernet | 150 Mbps | $20-25 | Бюджетный |
| **Huawei E8372h** | WiFi Hotspot | 150 Mbps | $35-45 | Встроенный WiFi |

### Режимы работы модемов

| Режим | Интерфейс | Настройка | Примечание |
|-------|-----------|-----------|------------|
| **HiLink/Ethernet** | eth1/usb0 | Plug-and-play | Модем = роутер, даёт IP по DHCP |
| **Stick/PPP** | wwan0 | ModemManager | Нужна настройка APN |
| **RNDIS** | usb0 | Plug-and-play | Windows-стиль, но работает в Linux |
| **QMI/MBIM** | wwan0 | qmicli/mbimcli | Современный, быстрый |

### ⚠️ Проблемные модемы

| Модем | Проблема |
|-------|----------|
| Модемы с только WiFi режимом | Нельзя подключить напрямую |
| Очень старые 3G модемы | Медленные, часто несовместимы |
| Залоченные на оператора | Нужна разлочка |

## 🔌 Блоки питания

### Для Raspberry Pi 4/5

| Тип | Требования | Рекомендация |
|-----|------------|--------------|
| **Официальный** | USB-C, 5.1V 3A (15W) | ⭐ Лучший выбор |
| **Качественный** | USB-C, 5V 3A+ | Anker, RAVPower |
| **С USB устройствами** | USB-C, 5V 4A+ | Если много USB |

> ⚠️ **Важно**: Дешёвые блоки питания = нестабильность, зависания, повреждение SD карты!

### Для Raspberry Pi 3

| Тип | Требования |
|-----|------------|
| **Стандартный** | micro-USB, 5V 2.5A |
